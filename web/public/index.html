For developers

An SMS API that just works

Send OTPs, transaction alerts and notifications, and check your balance, with a few lines of code.

  • Create API keys from your dashboard in one click
  • Same prices as the dashboard, same wallet
  • Ghana numbers like 024… are converted to 23324… for you
POST /api/v1/send-sms
curl -X POST https://your-kebsend-host.com/api/v1/send-sms \
  -H "Authorization: Bearer ksnd_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "to": "233240001234",
    "message": "Your verification code: 9482",
    "senderId": "MYSHOP"
  }'
const res = await fetch('https://your-kebsend-host.com/api/v1/send-sms', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer ksnd_live_...',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    to: '233240001234',
    message: 'Your verification code: 9482',
    senderId: 'MYSHOP'
  })
})
console.log(await res.json())
import requests

res = requests.post(

FAQ

Questions people ask

Is there a monthly fee?+

No. You buy credits when you need them and only pay for the messages you send.

How do I pay?+

Top up from your dashboard with MTN MoMo, Telecel Cash, AT Money, Visa or Mastercard. Payments are handled securely by Paystack and credits are added straight away.

What is a sender ID?+

It's the name people see when your message arrives, like MYSHOP. It must be 3 to 11 letters or numbers. You can request one from your dashboard and track its approval there.

How long can my message be?+

One SMS holds 160 normal characters, or 70 if you use emoji or special characters. Longer messages are sent as several parts, and each part uses one credit. The calculator above shows you the count.

Can I upload my contact list?+

Yes. Upload a CSV or TXT file, or paste numbers directly. Duplicates and invalid numbers are filtered out, and local numbers like 0244… are formatted automatically.

Can I send to other countries?+

Yes, to 190+ countries at GH₵ 0.08 per SMS.
